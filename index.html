문제

반복적인 응답 지연과 일부 해외 법인의 시스템 전체 지연이 발생했습니다.

접근

AI로 병목 후보를 도출한 뒤 실제 실행 통계로 검증했습니다. 모니터링 조회로 인한 DB 포화와 API 서버의 회복 구조를 분석하고, 개선, 복구 스크립트를 함께 준비해 검증 후 운영에 반영했습니다.

결과
